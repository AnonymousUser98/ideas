# Short, Simple Ideas
This is just a list of simple things that should exist. These ideas aren't very detailed or unique.

- 3DS Homebrew App: Back up the user's save data for _Team Kirby Clash Deluxe_ and then set their purchased gem apple count to 3000 (giving them the biggest tree).
- A way to boot directly into TWLMenu++ with a fastboot3DS boot slot.
- A way to have DS forwarders on 3DS tell games to go to TWLMenu++ instead of the 3DS HOME Menu when choosing _Exit game_ in the nds-bootstrap menu.
- A web browser replacement for Kobo eReaders that actually works with modern websites.
- WiiGSC that runs directly on the Wii.
- A FOSS PDF editor with a similar appearance and functionality as PDF X-Change Editor.
